# 단둘이 클릭형 알림 — 2026-09-25

## 사용 방법

1. 앱의 알림(종)에서 **기기 알림 받기**를 누르고 OS/브라우저 권한을 허용합니다.
2. 상대방이 데이트 최종 확정을 요청하거나 변경을 제안하면, Firestore 공유 알림 기록이 생성됩니다. 상대방이 승인을 완료한 경우에도 요청자에게 기록됩니다.
3. 대화 메시지와 새 추억의 기록도 수신자 계정으로 공유됩니다. 알림 목록의 항목을 누르면 날짜별 공동 데이트의 승인 창, 해당 채팅 메시지, 해당 앨범 항목으로 이동합니다.
4. 예전 알림은 항목 ID가 없으므로 관련 기능 화면으로 이동합니다. 승인 기록은 건별로 고유 ID를 가지며 반복 수신 시 중복을 방지합니다.

## 저장·권한·전송 정책

- `couples/{coupleId}/activity/{eventId}`에 두 사람이 볼 수 있는 이벤트를 저장합니다. 기록은 작성자/수신자 UID, 검증된 원본 문서 ID, 화면 목적지, 생성 시각으로 구성됩니다.
- Firestore 규칙은 같은 커플 이외의 읽기/쓰기를 막으며, 실제 존재하는 본인 메시지·추억 또는 승인 상태에 연결된 기록만 생성할 수 있습니다.
- 알림의 읽음/삭제는 사용자별 로컬 상태입니다. 원본 메시지·앨범·데이트 코스 내용과는 분리되어 있습니다.
- 브라우저 알림과 Android Local Notifications는 **앱이 실행되어 Firestore 이벤트를 수신하는 동안** 보조 알림을 표시합니다. 새 권한은 알림 화면에서 명시적으로 요청합니다.

## 배포 시 주의사항

**웹 탭을 완전히 닫거나 네이티브 앱 프로세스가 종료된 상태에서의 푸시 알림은 현재 제공하지 않습니다.** 실제 상시 백그라운드 수신을 지원하려면 서버의 Firebase Cloud Messaging 이벤트 발송, 장치별 FCM 토큰 등록 및 만료/로그아웃 처리, 웹 VAPID 키, Android google-services 설정과 실기기 검증을 별도로 구현해야 합니다. 현재 코드에서 Android PushNotifications.register()는 다른 권한 경로를 위해 존재할 수 있지만 FCM 서버 전송과 연결되어 있지 않으므로, 기기 권한을 허용하는 것만으로 종료 상태 푸시가 된다고 안내해서는 안 됩니다.
