# 통화·채팅·백업 안정화 검증 기록

## 범위와 배포 상태

PR #43의 기존 통화 수정에 이어 적용한 안정화 작업입니다. 홈 화면 비율, 테마, UI 배치는 변경하지 않았습니다.
유료 서비스 생성, Cloudflare 토큰 등록, 실제 Worker 배포, main 병합 및 운영 배포는 하지 않았습니다.
이 변경만으로 제한된 네트워크 사이의 통화 연결이 보장되지는 않습니다.

## 완료한 변경

- TURN 요청: 토큰 취득과 응답 본문 처리를 포함한 12초 제한, 동시 요청 합치기, 계정/커플/주소별 캐시 분리, 만료시간 검증, 취소된 응답 무시.
- 서버 미설정 시: 미배포 Firebase Function 주소로 요청하지 않고 직접 연결만 시도. Hosting의 미배포 Function 재작성 규칙 제거.
- Worker: 제한된 웹/Capacitor 원본만 허용, 로그인 및 커플 멤버십 확인, 요청 크기·문서 ID 검증, 공급자 JSON 오류 처리, 비밀값 비노출.
- 통화: 종료 즉시 미디어 트랙 정리, 늦은 권한/SDP/TURN 응답 차단, 오래된 비동기 실패가 새 통화를 종료하지 않도록 세대별 검사.
- 신호 기록: 취소된 발신·수락 트랜잭션은 신호를 게시하지 않으며, 이미 진행 중이던 저장이 끝난 경우 해당 통화 ID만 종료.
- 대기: 응답 없는 발신 60초, 연결 단계 35초 제한. 영상 전환 중복 요청 및 종료 후 남는 타이머 방지.
- 채팅: 전체 JSON 직렬화 대신 필드 비교, 변경 없는 메시지 객체 재사용, 이미 정렬된 목록의 불필요한 재정렬 방지.
- 채팅 화면 종료/대화 삭제: 지연 스크롤 타이머와 프레임 취소, 이전 쿼리 콜백 무시.
- 자동 백업: 계정별 저장 분리, 저장 중 추가 변경 보존, 이전 계정의 완료 응답 무시, 실패 시 최대 120초 간격 재시도.
- 백업 복원: 서버 상태 확인 후 저장 시작, 계정별 허용 키만 복원. 삭제된 키가 남지 않도록 값 전체를 교체하면서 문서 메타데이터는 보존.

## 검증

- `npm run stability`: 빌드, 런타임 36개, 사용자 흐름 95개, 네이티브 연결 검사, 교차 검사 78개, 의존성 39개, 번들 예산 검사 통과.
- `npm run test:security`: Auth/Firestore/Storage 에뮬레이터 14개 통과. 실제 프로덕션 사용자 데이터에는 접근하지 않음.
- 변경한 TypeScript 서비스/통화 컴포넌트에 대한 ESLint 및 `git diff --check` 통과.
- 추가 회귀 검사: 권한 대기 중 종료, 토큰/네트워크/JSON 무응답, 계정 변경, 오래된 응답 도착, 잘못된 TURN 데이터, Worker 인증 거부, 메시지 삭제·반응·갤러리·순서 보존.
- 최대 JS 청크 542.2 KiB / 예산 700 KiB, 시작 CSS 173.7 KiB / 예산 190 KiB. Vite의 일반 500 kB 경고는 남아 있으나 프로젝트 예산은 통과.

## 채팅 처리 측정

같은 실행환경에서 이전 커밋 `ef397d8`의 병합 함수와 새 함수를 비교했습니다.
2,000개 메시지(반복 텍스트, 사진 URL 2개, 반응 1개), 워밍업 15회 후 60회 측정한 중앙값:

| 항목 | 이전 | 변경 후 |
| --- | ---: | ---: |
| 메시지 스냅샷 병합 | 13.32 ms | 3.27 ms |

해당 연산 시간 약 75.5% 감소. 앱 전체의 로딩/스크롤 속도나 실제 휴대폰 성능을 뜻하지 않습니다.
임의 삭제·수정·역순을 포함한 300개 입력에서 기존 구현과 결과 일치도 확인했습니다.

## 남은 외부 검증

1. Cloudflare 접근 확보 후 Worker 배포 및 `TURN_API_TOKEN` 비밀값 등록.
2. GitHub Actions 변수 `VITE_TURN_CREDENTIALS_URL`에 공개 HTTPS 주소 등록. 웹 워크플로가 이 값을 빌드에 전달.
3. 검토·병합·배포 후 실제 두 기기에서 Wi-Fi/LTE 조합 음성통화, 영상 전환, 수신 취소, 권한 거절, 네트워크 변경 검사.

Worker 무료 요금제와 TURN 중계 사용 요금은 별개입니다. 실제 미디어 연결·지연·배터리 수치는 아직 측정하지 않았습니다.
