# 둘온 (Dul-on)

둘온은 커플 두 사람만을 위한 모바일 중심 비공개 공간 MVP입니다. 따뜻하지만 절제된 디자인으로 대화, 추억, 기념일을 한곳에서 관리합니다.

## 실행 방법

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`, 정적 미리보기는 `npm run preview`를 사용합니다. 현재 UI MVP는 별도 환경변수 없이 실행되며, 백엔드 연동 예시는 `.env.example`에 있습니다.

## 구현 범위

- 로그인·회원가입과 초대 코드 기반 커플 연결 데모 플로우
- 상대방 이름, D+ 날짜, 최근 추억과 최근 메시지를 보여주는 홈
- 메시지 입력과 즉시 전송이 가능한 1:1 채팅 UI
- 사진과 짧은 글로 구성된 반응형 추억 보관함
- 사귄 날짜 기준 D+ 및 다가오는 기념일 목록
- 모바일 하단 탭 내비게이션과 데스크톱에서도 앱처럼 보이는 반응형 레이아웃

현재 인증·초대 흐름은 실제 경험 검증을 위한 클라이언트 데모이며, 데이터 영속화 및 서버 기반 실시간 동기화는 다음 백엔드 단계에서 연결할 범위입니다. 현재 버전은 핵심 경험을 검증할 수 있는 프론트엔드 MVP입니다.

## 프로젝트 구조

```text
src/
├── App.tsx       # 화면, 내비게이션, 데모 상태와 상호작용
├── main.tsx      # React 진입점
└── styles.css    # 모바일 중심 디자인 시스템과 반응형 스타일
```

## 보안 설계 (백엔드 연동 시 필수)

모든 커플 소유 데이터에는 `couple_id`를 저장하고 클라이언트가 아닌 서버가 인증 토큰의 사용자로부터 이를 결정해야 합니다. API 쿼리는 항상 로그인 사용자의 `couple_id` 조건을 강제하며, 초대 코드는 단일 사용·만료·해시 저장합니다. WebSocket 채널 참가 역시 서버가 인증 후 동일 `couple_id`의 두 사용자에게만 허용해야 합니다. 사진은 비공개 스토리지에 저장하고 동일 권한 검사를 거친 짧은 만료 시간의 서명 URL로만 제공합니다.

> 이 저장소의 데모 데이터는 브라우저 UI에 포함된 샘플이며 실제 개인정보를 저장하지 않습니다. 실제 서비스 배포 전 인증·인가 백엔드 구현이 필요합니다.
