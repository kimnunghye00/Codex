# 단둘이 (DANDULI)

> **단** 하나의, **둘**만의 **이**야기.

**단둘이**는 연인 두 사람이 대화하고, 추억을 남기고, 일정과 위치를 공유하며 둘만의 시간을 이어가는 커플 커뮤니케이션 앱입니다.  
이름에는 “단 하나의, 둘만의 이야기”라는 뜻을 담았습니다.

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버가 안내하는 `http://localhost:5173`을 브라우저에서 엽니다. 프로덕션 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`를 사용합니다.

## 주요 기능

- Firebase 전화번호 SMS 가입·로그인, 이메일 로그인·비밀번호 재설정
- 첫 가입 후 이름, 생년월일, 성별, 이메일, 프로필 사진 설정
- 서로의 프로필과 함께한 날짜를 한눈에 보는 홈
- 가장 가까운 기념일과 함께할 일정을 보여주는 일정 기능
- 사진·영상·추억을 모아보는 앨범
- 사진 여러 장 전송, GIF, 답장, 반응, 예약 메시지 등을 지원하는 1:1 대화
- 둘이 방문한 장소와 이동 흐름을 확인하는 지도
- 앱 테마, 채팅 스타일, 프로필 스타일, 앱 아이콘을 바꾸는 꾸미기 기능
- Android / iOS / Web / Windows 확장을 고려한 멀티플랫폼 구조

## 브랜드

- **이름:** 단둘이
- **영문 표기:** DANDULI
- **브랜드 문장:** 단 하나의, 둘만의 이야기.
- **핵심 가치:** 둘만의 대화 · 추억 · 일정 · 위치 · 기록을 하나의 공간에서 이어가기

## 프로젝트 구조

```text
src/
├── components/
│   ├── auth/          # 인증, 프로필, 계정 설정
│   ├── chat/          # 1:1 대화와 채팅 도구
│   ├── home/          # 홈과 커플 도구
│   ├── location/      # 지도와 위치 기록
│   ├── memories/      # 추억, 기념일, 기록, 티어
│   ├── more/          # 꾸미기와 더보기
│   └── navigation/    # 상단/하단 내비게이션
├── lib/               # Firebase·네이티브 연동
├── utils/             # 저장, 날짜, 프로필, 앱 아이콘 유틸리티
├── App.tsx
├── Root.tsx
└── main.tsx
```

## 데이터와 보안

커플 소유 데이터에는 `couple_id`를 사용하고, 실제 서비스에서는 서버가 인증된 사용자 기준으로 접근 권한을 확인해야 합니다. 사진과 영상은 비공개 스토리지와 권한 검사를 통해 제공하는 구조를 권장합니다.

현재 프로젝트에는 기존 설치본과 Firebase 연결을 깨뜨리지 않기 위해 일부 내부 호환성 식별자와 저장 키가 과거 명칭으로 유지될 수 있습니다. 사용자에게 표시되는 제품 브랜드는 **단둘이**를 기준으로 합니다.

> 저장소의 데모 데이터는 UI 확인용 샘플이며 실제 개인정보를 의미하지 않습니다.
